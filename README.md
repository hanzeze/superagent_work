# superagent_work

This repository is the work target for dsh-superagent.

## 简介

本仓库是 dsh-superagent 的工作目标仓库，用于承接由 superagent 自动创建的分支与 Pull Request。

## 目录结构

```
superagent_work/
└── README.md   # 项目说明文档
```

## 快速开始

```bash
git clone https://github.com/hanzeze/superagent_work.git
cd superagent_work
```

## 使用说明

- Issue / PR 中的任务由 superagent 自动处理；
- 自动变更通过 `agent/<ticket-id>` 分支提交 PR；
- 人工 review 后合并到 `main`。
